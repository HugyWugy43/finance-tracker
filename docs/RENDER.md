# Бесплатное размещение на Render и Turso

Render запускает Node-сервер, а Turso хранит аккаунты и операции вне временной файловой системы Render. Локальная D1 остаётся доступна через обычный `npm run dev`; её данные не копируются в интернет.

## Настройки сервиса

- Тип: Web Service, Node, план **Free**.
- Репозиторий: `https://github.com/HugyWugy43/finance-tracker`, ветка `main`.
- Root Directory: пусто (папка `orbit` уже является корнем Git-репозитория).
- Build Command: `npm ci --include=dev && npm run build:render`.
- Start Command: `npm run start:render`.
- Health Check Path: `/api/health`.
- `NODE_VERSION=24.15.0`.
- `TURSO_DATABASE_URL`: адрес новой базы `libsql://…`.
- `TURSO_AUTH_TOKEN`: ключ чтения и записи этой базы, только в секретах Render.

Те же настройки описаны в `render.yaml`. Не включайте платный тариф или платное превышение квот. Бесплатный Render засыпает после простоя, поэтому первый запрос может ожидать запуска сервера. База при этом сохраняется в Turso. При подключении по публичной ссылке GitHub обновление сервиса запускается вручную через Manual Deploy.

## Запуск и миграции

Команда старта сначала применяет SQL из `drizzle/` к Turso, затем запускает production-сервер Vinext на `0.0.0.0:$PORT`. Таблица `orbit_migrations` хранит список применённых миграций и контрольные суммы: повторный запуск не пересоздаёт таблицы и не очищает операции. Уже применённые миграции нельзя менять; изменения схемы добавляются новым файлом.

На Render запрещён запуск с файловой базой вместо удалённой. Ключ базы не нужен при сборке и не передаётся клиентскому JavaScript. Сервер доверяет HTTPS-заголовку прокси Render, чтобы cookie сессии получала Secure и проверка Origin работала за прокси.

## Проверка перед публикацией

`npm run build:render` проверяет production-сборку. Для локальной проверки можно задать `TURSO_DATABASE_URL=file:./test-results/render-test.db`, создать папку `test-results`, задать `PORT=4174` и выполнить `npm run start:render`. Это отдельная тестовая база, не локальная D1. Затем запустите тесты с `ORBIT_URL=http://127.0.0.1:4174`.

`node tests/turso.mjs` проверяет адаптер базы, включая количество изменённых записей и откат транзакции при ошибке. На публичном сайте достаточно проверить `/api/health`, загрузку ресурсов и один тестовый аккаунт; полный негативный набор следует запускать на тестовой базе.

Ограничения бесплатных планов: https://render.com/docs/free и https://turso.tech/pricing. Тарифы и лимиты могут меняться.
