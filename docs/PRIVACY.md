# Данные, которые нельзя публиковать

## Результат проверки от 13 октября 2026 года

В проверенных текстовых исходниках не найдены явные ключи API, приватные ключи и URL со встроенными паролями. Поиск характерных сигнатур секретов в доступной истории Git (один коммит, 149 объектов файлов) также не дал совпадений. Это эвристическая проверка, а не гарантия отсутствия любых секретов или полный аудит безопасности. Зависимости и содержимое изображений не проверялись как исходный код.

В локальной базе есть аккаунты, сессии и финансовые операции. Их значения не выводились и данные не удалялись. Даже хеши паролей и токенов следует считать чувствительными данными.

В API-тесте фиксированный учебный пароль заменён случайным паролем для каждого запуска. Это не меняет уже созданные тестовые аккаунты. Строка с заведомо неверным паролем остаётся частью проверки отказа во входе.

## Где могут находиться личные данные

| Место                                | Что учитывать                                                                                 |
| ------------------------------------ | --------------------------------------------------------------------------------------------- |
| `.wrangler/state/`                   | Имена, почта, хеши паролей и сессий, записи о доходах и расходах                              |
| `test-results/`                      | Снимки экранов и отчёты могут содержать данные, отображённые приложением                      |
| `.env*`, `.dev.vars*`                | Если создать эти файлы, в них могут оказаться секреты окружения                               |
| CSV, копии SQLite и другие выгрузки  | Могут содержать реальные финансовые операции                                                  |
| Отчёты в соседнем каталоге `report/` | Могут содержать ФИО автора и скриншоты с личными данными; проверяйте отдельно перед передачей |

## Перед передачей проекта

Передавайте исходники, миграции, ресурсы, инструкции и `package-lock.json`. Не включайте локальную базу, резервные копии, файлы сессий, секреты окружения и личные выгрузки. Зависимости и кеши также не нужны: они восстанавливаются при установке и сборке.

`.gitignore` исключает локальные данные из новых добавлений в Git, но не удаляет уже отслеживаемые файлы и не фильтрует ZIP-архивы. Перед коммитом просмотрите `git status --short` и `git diff --cached`. Перед отправкой архива проверьте его содержимое отдельно.

Не удаляйте базу только ради подготовки проекта к передаче: соберите архив из исходников, сохранив личную рабочую копию. Если действующий секрет когда-либо был опубликован, сначала отзовите или замените его у поставщика; удаления строки из текущей версии недостаточно.
