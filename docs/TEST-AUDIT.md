# Аудит тестов ORBIT — 15 октября 2026 года

## Вывод

Существующие тесты выполняют реальные проверки, а не просто печатают успешный результат. Исходный набор из 253 проверок прошёл на локальном сервере, однако дополнительные негативные сценарии обнаружили три ошибки API и отсутствующее изображение профиля. Это показывает, что успешный прогон не означает полного покрытия приложения.

В `verify.mjs` встречается `check(name, true)`: непосредственно перед ним выполняется Playwright `waitFor()` для результата действия. Если результат не появляется, ожидание выбрасывает ошибку и процесс завершается неуспешно. Это не фиктивная проверка, хотя некоторые сценарии подтверждают только появление элемента, а не всю цепочку сохранения данных.

## Что проверяется

| Набор                   | Способ проверки                                                                                                                                               | Ограничения                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `verify.mjs`            | Настоящий API, регистрация и вход, изоляция пользователей, CRUD, бюджет, действия через Chrome                                                                | Часть действий проверяется по статусу ответа; нет полного перебора всех ошибок                    |
| `adversarial.mjs`       | Настоящие HTTP-запросы: неправильные типы, границы сумм и дат, некорректный JSON, размер тела, Origin, повторное использование отозванной сессии, лимит входа | Не нагрузочный тест и не полный аудит безопасности                                                |
| `usability.mjs`         | Chrome, фиксированная дата, заранее заданные ответы API, расчёты и взаимодействие с интерфейсом                                                               | Не подтверждает работу базы; анимации выключены                                                   |
| `chart-readability.mjs` | Геометрия диаграммы, малые расходы, реальные шрифты, адаптация                                                                                                | Геометрические проверки не заменяют визуальную оценку; API подставлен                             |
| `visual.mjs`            | Переполнение, reduced motion, наличие логотипа и его цвет                                                                                                     | Нет сравнения пикселей с эталонными скриншотами                                                   |
| `project-health.mjs`    | Профиль, навигация, размеры аватара, ошибки JavaScript, декодирование изображения                                                                             | Подставленные ответы API; отсутствие pageerror само по себе не означает отсутствие сетевых ошибок |

## Воспроизведённые ошибки и исправления

| Ошибка                            | До исправления                                                                                                                      | Исправление и регрессия                                                                                                  |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Обход ограничения входа пробелами | После 10 неудачных входов адрес с пробелом получал 401 вместо 429, потому что поиск аккаунта обрезал пробелы, а ключ счётчика — нет | Ключ ограничения использует `trim().toLowerCase()`; проверяются исходный адрес, пробелы с обеих сторон и верхний регистр |
| Неверный тип счёта                | `account: ["Основной счёт"]` сохранялся с ответом 201 из-за преобразования массива в строку                                         | Валидация требует строку; негативный запрос должен вернуть 400 и не оставить запись                                      |
| Неполная проверка источника       | Origin с тем же адресом и портом, но другой схемой принимался с ответом 200                                                         | Сравнивается полный origin, включая схему; неверный источник получает 403                                                |
| Отсутствующее изображение профиля | Ссылка на уже удалённый `chrome-orbit.jpg` не мешала старому тесту пройти                                                           | Профиль использует существующую звезду; тест требует успешного декодирования изображения на восьми ширинах экрана        |

Новые тесты сначала запускались на старом поведении и завершались с ошибками. После исправлений те же проверки прошли. Удалённый ранее JPG не восстанавливался, личные записи не редактировались.

Дополнительно усилена проверка шрифтов: одного `document.fonts.check()` недостаточно, поскольку при отсутствии объявленного шрифта браузер может использовать запасной. Теперь тест загружает требуемый шрифт и проверяет непустой набор загруженных FontFace.

## Результат и запуск

После изменений: 44 + 34 + 110 + 40 + 6 + 61 = **295 успешных проверок**. Это количество утверждений, включая повторы на разных размерах экрана, а не 295 независимых пользовательских сценариев. `npm run typecheck` и `npm run lint` также завершились успешно.

В одном терминале запустите `npm run dev`, в другом — `npm test`. Для отдельного прогона негативных сценариев есть `npm run test:adversarial`. Адрес сервера задаётся переменной `ORBIT_URL`; по умолчанию используется `http://127.0.0.1:5173`. Отчёты и скриншоты записываются в `test-results/`, новый набор сохраняет результаты и при неуспешных утверждениях. Не считайте старый JSON подтверждением нового запуска: проверяйте дату и код завершения команды.

API-тесты создают аккаунты со случайными адресами домена `example.test` в базе выбранного сервера. Новый набор удаляет созданные операции, но тестовые аккаунты и счётчики попыток остаются. Запускайте тесты на локальной тестовой базе, не на рабочем публичном сервисе.

Сборка `npm run build` в этой среде остановилась с `EPERM` при очистке `dist`, в том числе при запуске с расширенными разрешениями. Поэтому результат аудита подтверждён для dev-сервера; production-сборка этим прогоном не подтверждена. Права каталога и возможную блокировку файлов процессом необходимо устранить перед повторной сборкой.

## Что ещё не покрыто

Нет измеренного покрытия строк и ветвей, нагрузочного прогона, автоматической проверки всех правил доступности, тестов других браузеров, истечения срока сессии, сбоев базы и восстановления сети, гонок одновременных запросов и полного набора сценариев CSV-экспорта. Проверки вёрстки с отключёнными анимациями не подтверждают плавность переходов. Проекту полезно развивать эти направления, но текущие результаты не следует представлять как гарантию отсутствия всех ошибок.
